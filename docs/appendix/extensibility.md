## Transformers

Transformers are executed after HTML document has been parsed and before OpenXml conversion.
Unlike `HtmlFragment`, which intentionally exposes only a limited HTML-element abstraction, transformers receive the full AngleSharp `IDocument` instance and therefore have unrestricted access to the underlying DOM tree and parser ecosystem.

Transformers are executed sequentially, in the order they are registered.

**Typical use cases**

- Rewrite or normalise HTML generated by third-party systems.
- Inline external stylesheets.
- Process MathML or non-HTML elements.
- Manipulate document metadata or content in the `<head>` section.
- Rewrite image URLs or resource references.
- Integrate AngleSharp-based extensions and services
- Apply organisation-specific preprocessing rules before conversion

```csharp
converter.Transformers.Add(new CorporateTransformer());
```

```csharp title="CorporateTransformer.cs"
public sealed class CorporateTransformer : IHtmlTransformer
{
    public Task TransformAsync(AngleSharp.Dom.IDocument document, CancellationToken cancellationToken)
    {
        foreach (var note in document.QuerySelectorAll(".internal-note")
        {
            note.Remove();
        }
    }

    return Task.CompletedTask;
}
```

## Parser Configurators

Parser Configurators provide access to the underlying AngleSharp parsing infrastructure used by `HtmlConverter`.
They execute before any HTML is parsed and allow applications to customise the `AngleSharp.IConfiguration` used to create the document and browsing context.
This extension point is intended for advanced scenarios that require access to AngleSharp services or third-party AngleSharp extensions.

**Typical use cases**

- Enable support for AngleSharp extensions such as `AngleSharp.Css`.
- Register custom services in the browsing context
- Configure resource loaders and request pipelines

```csharp
converter.ParserConfigurators.Add(new CssParserConfigurator());
```

```csharp title="CssParserConfigurator.cs"
public sealed class CssParserConfigurator : IHtmlParserConfigurator
{
    public IConfiguration Configure(IConfiguration configuration)
    {
        return configuration.WithCss();
    }
}
```

## Processing Order

The loading pipeline executes in the following order:

1. Create the default `AngleSHarp.IConfiguration`.
2. Apply all registered parser configurators.
3. Create the `IBrowsingContext`.
4. Parse the HTML document.
5. Execute OnDocumentLoadedAsync().
6. Execute all registered transformers.
7. Return the resulting `HtmlFragment` or continue with OpenXml conversion.
