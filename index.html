Html to OpenXml

Faithfully translates rich HTML markup into professional OpenXML DOCX files.

Get StartedDocumentation

Wide Source Compatibility

Accepts and parses both legacy (HTML 4) and modern web markup (HTML5).

Deep Structural Fidelity

Supports complex HTML structures, including nested tables, rowspan and colspan.

Precise Layout Control

Provides detailed control over text flow (LTR/RTL), list continuation, and numbering structure.

Granular Style Mapping

Translates granular HTML classes into specific Word styles, allowing deep visual customization.

Robust Hyperlinking

Supports internal anchors and external URIs, ensuring reliable cross-document linking.

Flexible Resource Handling

Seamlessly manages media embedding and linking, supporting local paths, network shares (\\server), and Data URIs.
